# 相同smear输入与迭代停止阈值的纯求解比较

当前仍在运行，本文是报告结构，不是最终成绩。最终以summary.json和关闭后的原始记录补齐。

按用户最终要求：同一个24×24×24×64组态，四方向一次stout平滑，参数0.125，
质量参数−0.277，Clover系数1.160920226，原点单位源4自旋×3颜色，共12列。
两个求解器的迭代停止参数均为相对残差1e-8，即十的负八次方。
这里指各自求解方程的收敛阈值，不是两套解相互比较的误差。

主指标为初始化后完整12列原生求解调用墙时。读入、smear、布局准备、Clover和逆的
构造、多重网格建层、最终写盘与外部验算不计入此指标。必要的同列补偿求解计入。
没有把单列计时乘12，也没有用旧1e-10试算或此前未smear的4.33秒替代本轮结果。

我们的程序采用原生混合精度多重网格，PyQCU采用其CPU KUPL后端的双精度
奇偶预处理BiCGStab。双精度选择用于满足这次精度，不把4.33秒的complex64配置
直接当作1e-8可用配置。编译器与运行库沿用各自实际验证过的配置，独立进程加载，
没有把两套OpenMP运行库混入同一进程。

共同输入直接来自已保存的双精度stout后规范场，不重复或分别进行smear。
PyQCU只转换布局并在时间边界施加一次负号；我们的库内部施加同样反周期条件。
统一布局与归一化后的一列解辅助比较已通过；辅助解差不参与迭代停止决定。

## 测量约定

- 真实 LIME 输入：24³×64 和 32³×64；MPI grid 均为 `1,1,1,16`。
- 24 格块 `6,6,6,4`，mass `-0.277`，csw `1.160920226`；
  32 格块 `8,8,8,4`，mass `-0.279`，csw `1.1606789224`。
- 一次 stout：steps=1、rho=0.125、dir_ignore=4（四方向参与）；时间反周期。
- 每格只建层一次，单列和完整 12 列分别跑三次，每次零初值；每批两列。
- 预热后值为第二、第三次的中位数，保留全部样本。共享 batch 计时只计一次。
- node5005：8 NUMA、每域 2 MPI、setup/solve 每进程 16/12 线程。
- 灵晟 cn19688：16 NUMA、每域 1 MPI、setup/solve 每进程 37/32 线程；
  Donau 作业 `2144729`，592 CPU、480000 MB，计算节点编译和运行。
- FP32 MG 热路径，FP64 可靠更新及完整真残差，外部 complex128。
  额外 API correction solve 与内部可靠更新分开理解。
- 读入、stout、Clover/加载、setup、纯求解、完整 API 和独立验证分别记录。
  API 墙钟为 MPI 最大值；native solver 为 rank 0 的批计时求和。

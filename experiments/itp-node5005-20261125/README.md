# ITP node5005 求解和组态生成

Slurm 作业 `1305916` 指定 `amd256c_2025` 的 `node5005`，独占 256 核，时限 10 小时。
运行目录为 `/public2/home/lwb_720/itp-node5005-20261125`，源提交为
`b68c5586c8cd606112693e544a0544667f36cd38`。两颗 EPYC 9755 的 256 个物理核
分布在 8 个 CPU NUMA 域。求解阶段每域 2 MPI，每 rank 16 线程。RHMC 每域
8 MPI，每 rank 4 线程。各阶段分时使用这次全节点分配。

## 求解

C24 使用 `cfg_5000` 的 `verified-inputs` 版本，C32 使用 `cfg_10000`。两者与
灵晟求解基准的 SHA-256 相同。使用 `t=0` wall 单列，从零初值求解三轮，复用同一层次。
以第二轮纯求解时间比较。完整 Wilson–Clover 相对残差由独立标量程序复核至 `1e-8`。
C24 和 C32 的聚合块分别为 `6×6×6×4` 和 `8×8×8×4`，每 rank 粗层 8 线程。

## C24 组态生成

从灵晟已复核的 `hmc_000008.lime` 开始新的 2+1 味 RHMC 重质量试验链。
使用 `β=5.6`、`m_l=0.5`、`m_s=0.8`、`cSW=1` 和种子 `6452`，共 8 条轨迹，
前 2 条为预热。产物保存为 LIME 与对应 RNG 状态，检查 SciDAC CRC、SU(3)、
plaquette 和两个质量的独立算子像。

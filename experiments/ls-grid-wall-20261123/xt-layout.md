# C24 的 x/t 切分实验

同一 `24³×64` 组态和 `t=0` wall source，完整 Wilson–Clover 相对残差要求
`1e-8`。灵晟单节点使用 32 MPI × 16 线程。按最新要求，后续实验默认只测单列，
保留预热，结果取第二轮纯求解时间。已启动的旧 12 列作业已停止。

## Halo 交换原型

作业 `2234434` 在 `cn12053` 上对比 `1×1×1×32` 和 `2×1×1×16`。
原型按 native 的 `6×6×6×2` 聚合块选择细层和粗层面尺寸，用带 rank 与方向
标记的缓冲区复核通信结果。每个样本为 60 次打包和双向交换的平均耗时，取
32 个 rank 中的最大值。下表取每种配置的第二个样本。

| 交换 | t 切分（毫秒） | x/t 切分（毫秒） |
| --- | ---: | ---: |
| 细层，1 RHS | 2.628 | 2.122 |
| 细层，2 RHS | 4.835 | 4.290 |
| 粗层，1 RHS | 0.097 | 0.133 |
| 粗层，2 RHS | 0.136 | 0.166 |

x/t 切分让每 rank 的细层发送量从 2,654,208 字节降到 1,769,472 字节
（单 RHS），不依赖 halo 的细层格点比例从 0 增至 41.7%。粗层发送量保持
49,152 字节（单 RHS），每 rank 的出站消息从 2 条增至 4 条。该原型测量
打包和 MPI 交换，不含算子、全局归约或多重网格求解。

## Grid 的真实组态对照

首次尝试 `2×1×1×16` 时，Grid 的粗层本地时间长度为 2，默认时间向 SIMD
和粗层红黑布局触发断言。对照的两次求解均采用同一二进制，并将单精度 vector
lanes 放在 y 方向。聚合块、源、残差约束和 32 MPI × 16 线程保持一致。
测试入口用 `LS_GRID_MPI_XYZT` 选择进程拓扑，本次分别设置为
`2.1.1.16` 和 `4.1.1.8`。两个作业均使用 `GRID_SPATIAL_SIMD=1` 和
`LS_RANKS_PER_NODE=32`。

| Grid 进程网格 | 单列第二轮（秒） | 外层迭代 | 完整相对残差 |
| --- | ---: | ---: | ---: |
| 参考 `4×1×1×8` | 145.224 | 65 | `8.96e-9` |
| x/t `2×1×1×16` | 138.953 | 65 | `8.96e-9` |

两个作业都在 `cn12042`，本次 x/t 的第二轮比参考切分少 4.3%。较早一次 x/t
在同一节点用相同 SIMD 布局测得 99.162 秒，跨作业波动大于这次对照的差值。

## Native 后端的范围

生产 native 仍采用 t-slab。x/t 的正式接入需要同时改动规范场和 Clover 的
局部装载、建层的聚合块所有权、细层和粗层 halo、FP64 完整残差算子，以及
独立残差复核。Halo 和 Grid 测量为选择拓扑提供依据，不能当作 native 的
端到端耗时。

灵晟实验入口默认只测单列。native 默认传入 `--single-only`，独立复核也只读取
第二轮的一个解。普通实验的比较口径是预热后第二轮的纯求解时间。
